# Como Ver os Logs da Edge Function (PASSO A PASSO)

## 🎯 Objetivo
Ver qual é o erro exato que está acontecendo na Edge Function

---

## 📋 PASSO 1: Acessar o Supabase Dashboard

1. Abra: https://rhesplerpuaibdvyoety.supabase.co
2. Faça login se necessário

---

## 📋 PASSO 2: Ir para Edge Functions

1. No menu lateral esquerdo, clique em **"Edge Functions"**
2. Você verá a lista de funções

---

## 📋 PASSO 3: Ver os Logs

1. Clique na função **"create-payment-link"**
2. Procure por uma aba ou botão chamado **"Logs"** ou **"View Logs"**
3. Clique em **Logs**

---

## 📋 PASSO 4: Copiar o Erro

1. Você verá uma lista de logs (mensagens)
2. Procure pela mensagem de erro mais recente (geralmente em vermelho)
3. **Copie TODO o texto do erro**
4. **Me envie aqui**

---

## 🔍 O que procurar nos logs:

Você vai ver algo como:

```
Error: ...alguma mensagem...
```

ou

```
Failed to decrypt credential
```

ou

```
Provider pushinpay not configured
```

**COPIE E ME ENVIE** essa mensagem completa!

---

## ❓ Não encontrou "Logs"?

Tente:
- Procurar por "Invocations"
- Ou "Function Logs"
- Ou ir direto: https://supabase.com/dashboard/project/rhesplerpuaibdvyoety/functions/create-payment-link/logs

---

## 📸 Alternativa: Tirar Screenshot

Se não conseguir copiar o texto:
1. Tire um print da tela dos logs
2. Me envie a imagem
